# 开业场景强随机生成器

离线 Python 桌面小工具。点击“重新随机”，独立抽取12个维度，立即生成完整提示词；复制后与参考图一并提交给你使用的绘图工具。**只输出提示词，不接入出图服务，不需要账号、API Key或网络。**

## 启动（Windows）

安装 Python 3.10 或更高版本，安装时保留 Tcl/Tk（官方安装器默认包含）。双击本文件夹的 `启动.bat`。

也可以在本文件夹执行：

```powershell
python app.py
```

没有第三方 Python 依赖，无需 `pip install`。不要只单独复制 `app.py`，整个文件夹一起移动即可。

## 使用

1. 启动后自动显示第一组；再次启动恢复上次参数及提示词。
2. 点击“重新随机”：所有未锁定维度分别重抽，立即更新右侧提示词。
3. 勾选某项右侧的锁定框，可保留品牌、比例或其他条件；输入框也支持直接编辑。
4. 默认开启“强随机轮换”：使用候选池的维度独立抽取，用完一轮后再重复，且不沿用上一轮值。取消勾选后为普通随机，仍避开上一轮值。
5. 默认开启“品牌和街道随机组合”：品牌的西文和中文由同一组音节生成，街道由词根、道路类型和门牌号组合；两者分别避开最近200次完整重复。关闭此选项后使用可编辑候选池。
6. 点击“复制提示词”，粘贴至绘图对话并附上参考图；也可导出 UTF-8 TXT。

右侧提示词可以直接修改。手动修改后，参数变动不会静默覆盖文字；点击“更新提示词”或“重新随机”时会先确认是否替换手动编辑。复制和导出始终使用右侧当前文字。

## 12维

| 维度 | 默认候选数量 |
|---|---:|
| Logo 图形形态 | 20 |
| Logo 视觉结构 | 48 |
| 品牌名称 | 32个对应音节组合为2～3音节的新名称 |
| 地理位置 | 159（143个城市＋16个城市/区县选项） |
| 街道地址 | 40×40组词根 × 4类道路 × 999个门牌号 |
| 门店建筑风格 | 20 |
| KT板布置位置 | 16 |
| 气球造型 | 16 |
| 拍摄角度 | 10 |
| 天气及光线 | 8 |
| 画面比例 | 7 |
| 室内 / 室外 | 2 |

品牌为自造西文名称，中文按固定音节近似音译对应，不是已有外语词汇的语义翻译。例如 `LUMINA → 露米娜`。随机生成并不保证商标唯一。

行业和开业文案是额外的可编辑设置，不占用12维。行业默认美业，也可选择或输入其他行业。品牌名称和地址均为设计示例；城市与街道独立抽取，不代表真实门店地址。建筑与摆放位置也独立抽取，绘图时由提示词要求合理实现。

“固定要求 / 补充”默认保留3.5×2.2米横版大板、参考图板面的印刷图案与配色、参考图气球配色及真实手机摄影。背景与气球颜色跟随实际参考图；门店环境、摆位、Logo和气球形态按本轮参数创建。

## 自定义与独立存储

点击“编辑参数池”，选择维度，每行填写一个候选值，保存全部参数池。每维至少两个不同选项；品牌和街道候选池仅在关闭“品牌和街道随机组合”时使用。保存后保留当前显示内容，下一次随机使用新池。

| 路径 | 职责 |
|---|---|
| `app.py` | 唯一启动入口 |
| `scene_tool/config/` | 维度定义、路径、品牌音节、街道词根、200条文案素材 |
| `scene_tool/domain/` | 参数池校验与升级规则、提示词组装 |
| `scene_tool/generation/` | 参数抽取、品牌生成、街道生成、文案组合及防重复 |
| `scene_tool/storage/` | JSON原子写入、参数池加载、会话文件读写 |
| `scene_tool/ui/` | 窗口组装、参数面板、提示词面板、编辑交互、参数池弹窗、设置绑定与主题 |
| `resources/` | 默认参数池和旧版参数池识别数据 |
| `tests/` | 核心行为、模块集成和旧数据兼容性检查 |
| `data/` | 用户设置、随机历史、自定义参数池；保持旧版本路径不变 |

所有运行数据仅在本工具的 `data/` 中，不读取或修改其他工具的数据。请放在可写目录中。若目录不可写，界面会提示保存失败，仍可复制或导出提示词。关闭程序后删除 `data/` 可恢复默认设置。运行数据不提交到 Git。

手动指定的值可能打断某维当前轮换顺序；当手动值恰好等于最后一个剩余项时，优先保证下一次不沿用该值，开启新一轮。强随机保证参数轮换，不保证绘图模型绝对不产生视觉相似的结果。

## 开发检查

```powershell
python -m unittest discover -s tests -v
```

测试覆盖12维独立采样、跨多轮防重复、候选池轮换、锁定、自定义值、状态存储及提示词约束。Windows 界面和双击启动需在本机实测。

## 随机开业文案

内置 **200条完整短句：100条主标题＋100条副句**，前后独立抽取，形成10,000种搭配。素材采用跨行业通用开业表达，不自动添加折扣、赠品、日期或服务承诺。

默认勾选“随机开业文案”，点击“重新随机”时与12维参数一起更新。文案行右侧可锁定；取消随机勾选也可保留手写文案。“全部解锁”同时解除文案锁定。12维全部锁定时，只要文案随机开启且未锁定，仍可单独随机文案。

每次避开上次的主标题和副句，并避开最近200组完整组合；历史、开关和锁定状态会保存。旧版设置升级后保留当前文案，下一次点击随机才生成新文案。右侧提示词手动编辑仍受原有覆盖确认保护。

素材位于 `scene_tool/config/copy_phrases.py` 的 `HEADLINES` 和 `SUBLINES`，可按需替换。两部分各自成句，可交叉组合；具体语气和搭配仍可在界面手动调整。文案不占用原有12个参数维度。

## 本轮结构整理

按功能目录拆分原有 `app.py`、`core.py`、`generators.py` 和 `copywriting.py`，旧平铺源码已移除。双击 `启动.bat` 和 `python app.py` 启动方式不变，不需要安装新依赖。已有 `data/state.json`、`data/custom_pools.json` 原位置读取，无需删除或搬动。

参数池编辑现在保留品牌/街道的最近生成历史，并保留未修改参数池的剩余轮换记录。替换了候选项的维度从新池重新轮换。

## 手机实拍与装饰限制

生成提示词统一加入普通手机后置主摄、现场自然光、未经精修相册原片的要求，明确排除3D渲染、棚拍、广告大片、夸张HDR和塑料质感。保留自然光影与轻微现场痕迹，不靠故意模糊或明显噪点模拟真实。

开业装饰限定为KT板与气球，明确禁止实体鲜花、仿真花、干花、花束、花篮、开业花架、花环、花墙以及气球中的混合花材。参考照片有实体花艺时要求移除；板面印刷图案仍按参考图保留。

升级时自动替换未修改的旧默认要求并更新未手改的提示词。用户自定义固定要求和手改提示词保留；若右侧仍为手改的旧提示词，点击“更新提示词”并确认即可采用新规则。规则用于引导绘图模型，图片是否完全遵循仍需观察实际输出。

## 参考范围与生活化细节

新版默认要求明确：参考图只用于板面设计和气球配色，“只替换文字与Logo”只限定板面，不限制重新创建门店环境。照片比例与板材比例分别执行，允许为完整容纳装置后退；未指定其他参照物时，拍摄方向相对KT板正面。门廊阴影与街道亮度按实际时段自然呈现。

路人0—3人、车辆0—2辆，分别可有可无，也可以都没有；出现时不遮挡主体，车辆限可通车区域。这是提示词中的可选范围，由绘图模型决定具体呈现，不增加原有12维，也不保证每次出图的出现概率。

随机文案的两句分别标为主文案与副文案，并注明不印出界面的“｜”分隔符。自定义单句原文保留，不拆分其他标点。

原始默认模板与上一版手机摄影默认模板均可自动升级；自定义固定要求不会被改写。需要完整采用新版参考范围、空间与路人车辆规则时，点击“复原默认提示词”，必要时可“撤销复原”。提示词配置位于 `scene_tool/config/prompt_template.py`，文案排版规则位于 `scene_tool/domain/copy_layout.py`。

## 一键复原提示词

右侧“复原默认提示词”会恢复本版本默认固定要求、清空补充要求，并用**当前12维参数、行业及开业文案**重新组成完整提示词，包含手机实拍与禁花艺要求。直接点击生效，不重新抽取参数，不改变锁定和参数池。

“撤销复原”可在本次打开期间找回最近一次复原前的固定要求、补充要求与完整提示词；连续点击复原不会覆盖同一份有效快照。撤销仅恢复文字，不回退场景参数。复原结果会保存，撤销快照不跨重启保留。

天气候选仅包含日常天气与时段；拍摄角度以站立手持手机、后置主摄1倍为准，通过站位和距离变化。更新后解除天气及角度锁定并点击“重新随机”使用新候选；自定义候选池保留。

## 无控制台启动

双击 `启动.bat` 会使用同一 Python 安装目录的 `pythonw.exe` 独立启动界面，CMD 窗口自动退出，无需保留。正确关联 Python 的 Windows 也可直接双击 `app.pyw`，不会显示 CMD。

启动失败会弹窗并尽可能写入 `data/startup-error.log`。需要终端调试时仍可运行 `python app.py`。Windows 双击、进程独立运行和错误弹窗需本机验证。

## 室内与室外

第12项可随机、手动选择及锁定。室内模式使用独立室内摆位，并将拍摄位置转换为室内表达，第6项改用独立的内部装潢候选池；转换后的内容显示在完整提示词中，摆位与角度的左侧原始参数保留。天气只影响窗外及采光，室内不出现车辆。自定义参数仍需自行检查是否适合所选场地。旧设置默认补为室外，已有参数、锁定和手改提示词保留。

Windows 优先使用原生 vista 控件主题，内容未变化时跳过整段提示词重绘。没有为移动窗口绑定随机、保存或刷新任务；拖动流畅度仍需 Windows 本机验证。

Windows 拖动边框期间固定整个内容区域的像素尺寸，窗口外框可变化，内容可能暂时被裁切或留出空白；松开鼠标后统一适配新尺寸。通过鼠标主键的实际按下状态判断是否结束，不因中途停顿而恢复排版，不修改文本、换行设置或撤销记录。实际拖动表现需 Windows 本机验证。

## 室内装潢风格池

第6项随第12项切换：室外显示“门店建筑风格”（20项），室内显示“内部装潢风格”（60项），总维度仍为12。先确定场地，再从对应风格池随机，两套池分别轮换；编辑参数池可分别修改两套候选。室内风格素材位于 `scene_tool/config/interior_styles.py`。

锁定室内后，只随机室内装潢。切换室内外会替换第6项原场地风格，即使风格项已锁定，也不会将另一场地风格带过去；之后继续保留该项锁定。旧室内设置若仍使用默认建筑外观，会换为室内风格；手改完整提示词继续保留。

## 室内外摆位与气球

第6、7、8项一起随场地切换。室内使用60种装潢、24种KT板摆位、24种气球造型；室外使用20种建筑、16种摆位、16种气球造型。各池独立轮换并可分别编辑。气球造型的室内版本考虑层高、通道和固定方式，户外版本明确支架或配重固定。切换场地时这三项会换入对应池，已有锁定状态保留。旧默认气球池自动升级，自定义池保留。

## 多场景模式切换

窗口顶部的“场景模式”提供八种模式：原有开业场景，以及酒店门口、酒店大厅、包厢内、商品房套间内、别墅内、户外草坪婚礼、小区楼下。原开业模式保持12维及原有功能，新模式各自使用10维独立模型，不借用品牌、Logo、地址和开业文案。

| 场景 | 六个专属维度 |
|---|---|
| 酒店门口 | 建筑门面、入口结构、迎宾装置位置、门前通行空间、环境材质、现场人物 |
| 酒店大厅 | 大厅设计、空间结构、装置摆位、背景家具、地面材料、大厅活动 |
| 包厢内 | 包厢装潢、包厢平面、装置位置、餐桌关系、椅具形式、现场状态 |
| 商品房套间内 | 家居装潢、套间格局、装置位置、家具陈设、生活细节、家庭人物 |
| 别墅内 | 别墅室内风格、内部空间、装置位置、建筑内部特征、会客家具、来宾活动 |
| 户外草坪婚礼 | 草坪场地、场地布局、装置位置、远景环境、婚礼座椅、来宾分布 |
| 小区楼下 | 住宅建筑、楼下空间、装置位置、背景设施、地面铺装、居民活动 |

另四维为对应场地的气球布置、手机拍摄站位、时段或天气、画面比例。扩充后首项场地／风格60项，其余四个空间维度各40项，人物32项，气球56项，站位32项；室内时段4项、户外天气8项，比例7项。各模式可分别编辑全部候选池。每一维独立轮换，锁定项保持不变。

新模式默认保留参考装置的板材形状、数量、图案、文字、颜色和人物比例；不强制3.5×2.2米，也不自动改名或加入开业宣传。仍保持普通手机实拍与无新增实体花艺。具体尺寸或文字变更可在“补充要求”中填写。

切换时保留每个模式的参数、锁定、候选池、轮换记录、补充要求和手改提示词；重启恢复上次模式。新模式单独存入 `data/scene_modes.json`，旧 `data/state.json` 与开业自定义池继续使用。复原只重建当前模式提示词并清空当前补充要求，可在本次打开期间撤销。复制和导出均以当前文本为准。

场景资源分别位于 `resources/scenes/` 的七个JSON文件。通用模型、文件存储、界面布局、交互与切换分别在 `domain/scene_model.py`、`storage/scenes.py`、`ui/scenes/`，不把多个场景的逻辑堆入启动文件。Windows窗口操作与最终图片效果仍需本机验证。

## 场景候选扩充

七种新场景合计2,469条维度候选（原537条）。其中包含基础场景与具体空间组合变体，不等于2,469种完全独立的设计风格。随机时优先避免连续选择同一基础场景的细微变体；轮换池只剩同类候选时仍按完整候选轮换。旧版未修改的默认池自动升级并重建其轮换记录，手改候选池、当前参数、锁定及提示词保留。天气和时段保持简洁。
