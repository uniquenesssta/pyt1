# 随机策略与材质预设

四个近景辅助项保持在主界面；普通随机支持“主变化优先”和“全部随机”，材质预设保存描述及明确的表面属性。此前第一阶段文档中“移入辅助窗口”的操作已不适用。

## 随机方式

顶部“随机方式”对当前场景生效并保存。首次升级采用“主变化优先”；“全部随机”保留原方式，不修改当前值，下一次点“重新随机”才按所选方式抽取。四方案预览继续使用原来的差异筛选流程，不受普通随机策略限制。

| 模式 | 每次优先变化 | 每次另外轮换一组 |
|---|---|---|
| 开业买家秀/商业效果图 | 场地、空间风格、装置摆位、气球与机位；商业含展示空间/背景层次 | 地理信息；品牌/Logo/文案；光线；画幅 |
| 其他七场景 | 场景风格、装置摆位、活动或主体构图、机位 | 入口/细部与配套环境；其余装饰/场景细节；光线；画幅 |
| 近景摄影 | 镜头类别、机位、裁切、焦点与适用的景深字段 | 邻接边缘/留白；前后层次；自定义材质表现/外观保留；反光/亮光位置；画幅 |

只在当前模式实际存在的字段里抽取。辅助组按顺序轮换，跳过整组锁定、隐藏或已合并为固定保护要求的项目；其余辅助项依次参与变化。临时保留不改变用户的锁定勾选，也不消耗该项候选的轮换进度。未填完的可见字段会先补齐。

近景的机位、裁切、焦点与景深仍按镜头套系联动；反光与亮光位置仍检查相容性。锁定限制优先，冲突时提示。隐藏的关联字段可能为保持套系一致而内部调整，但不会重新出现在提示词里。其他隐藏项在主变化优先中保持。

两种随机方式均保留当前模式的手填锁定值。锁定依赖室内外的空间、摆位、气球或买家秀机位时，同时保持原场地；不改变“室内/室外”的锁定勾选。商业机位不依赖室内外，单独锁定它仍允许改变场地。临时保留的手填辅助值也不会在界面同步时被默认候选覆盖。

程序自带的“材质表现”和“外观保留重点”默认保护描述已统一到固定要求；纯默认保护池不再参与轮换和方案差异计数。界面取值与锁定仍保留，自定义补充继续单独输出、随机和隐藏。

这是抽取策略调整，不能保证生成图片的差异程度。没有删除候选，也没有把已抽定参数交给生图端再次随机。

## 材质外观预设

在近景主界面的“自定义材质”中写描述，在“材质表面”选择跟随参考、哑光、微光或亮面，再在“材质预设”中输入名称并保存。之后从下拉框选择，即可应用描述和属性到当前场景，重新组成提示词并保存场景。原有直接输入材质的方式继续可用。

- 八个场景共用本工具的一份预设文件，不同工具互不读写。
- 预设保存描述原文，边缘空格会清理；不自动添加布纹、金属、烫金或其他工艺。
- 预设保存材质描述与表面属性；主体名称、机位、画幅保持当前设置。反光和灯位在该属性允许的范围内继续随机。
- 哑光只配无明显光带；微光仅轻微反光；亮面允许微光、亮面或高光。反光“跟随材质”会按明确属性解释。修改属性时只调整未锁定且不兼容的反光/灯位；锁定冲突则拒绝本次修改。
- 不从自定义文字猜表面属性。“跟随参考”沿用参考描述，没有额外的材质数值约束；不代表程序已识别参考图。
- 旧纯文字预设读作“描述＋跟随参考”，不会因为名字带“哑光”而自动判定；成功保存时更新存储格式，损坏文件保持不变。
- 同名描述或表面属性变化时询问是否覆盖；删除时确认，当前材质描述和属性保留。
- 手改整段提示词时，调用预设会先确认；取消不修改材质及提示词。
- 保存使用原子替换；格式错误或无法读取时不以空字典覆盖文件，写入错误会提示。

材质预设用于复用用户确认过的表面描述，不能代替实物参考图。工具仍不读取图片，也不自动调用生图服务。
