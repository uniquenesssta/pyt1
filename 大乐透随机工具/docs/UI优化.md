# 现有桌面界面的局部优化

本轮按用户反馈纠正范围：保留现有 Tk/ttk 页面和功能，只调整控件尺寸、对齐、留白、空间分配与操作可见性。不以 Figma 设计稿作为实现目标。

## 截图中问题的修正

- 恢复 Windows 原生控件主题和按钮边界；去掉强制蓝白配色，标签选中前后使用一致的内边距。
- 随机模式和细分指标下拉框按内容设置宽度，不随窗口拉长。
- 减少页边距、工具栏与说明间隔；固定/排除的展开入口放入现有操作行。
- 底部状态栏、权重编辑区、历史复制区和结果金额摘要先预留空间，再由表格占用剩余空间，避免按钮被挤没。
- 统计上下区域按实际可用高度设置初始比例，用户之后仍可拖动分隔线；50/100/全部使用原生单选状态。
- 冷热号继续默认跟随普通统计，也可独立选50/100期。

## 重叠分析与处理

| 原有重叠或问题 | 处理 | 保留原因或边界 |
| --- | --- | --- |
| 跨区权重两处编辑，首次填入前可能各有一份值 | 有历史配置即双向联动；保留选号页一键填入快捷入口 | 同一个指标只参与一次评分 |
| 普通统计与冷热号各自选期，容易读错范围 | 冷热号默认跟随主范围；主动独立对比时明确标识 | 独立50/100对比仍有用，随时可恢复跟随 |
| 全部范围的去重规则不一致 | 冷热号全部与普通统计、回查一致保留原始重复行 | 结构权重全部仍维持原期号去重语义 |
| 统计分析与结构页都展示次数 | 普通统计负责查看，结构页负责分布、权重与强度编辑 | 窗口和用途不同，不强行合并 |
| 最长连号/连号形态、空区数量/各区空区有关联 | 保留细分指标，并明确默认关闭相关指标强度的原因 | 定义不同，不将历史次数粗略相加 |
| 图表、冷热号都有号码次数 | 合并在下半区视图切换，默认同范围 | 表格用于精确数字，图表用于比较 |
| 本批与收藏永久平分宽度 | 改为结果标签切换，显示数量 | 不删除收藏、复制、导出和批量操作 |
| 期数下拉改变即覆盖手工权重 | 显式点击统计或回车才应用，显示未应用提示 | 原统计双击仍按已展示快照回查 |
| 一页长下拉含所有结构指标 | 指标组+细分指标两级选择 | 19个原有指标全部保留，各出现一次 |
| 查询工具栏太密、来源列长期占空间 | 范围→条件→结果分层；来源列按需显示 | CSV和复制仍包含完整来源信息 |
| 固定/排除占用默认界面 | 默认收起，始终显示已启用条件摘要 | 收起不清空条件；长表单局部滚动 |
| 文档多轮追加后互相矛盾 | README按当前行为统一重写 | 历史验证记录保留日期与版本语义 |

## 交互规则

- 控件沿用系统样式，主操作以文字加粗区分；保留原生的选中、焦点和禁用状态。
- 表格交替底色、排序方向、选中计数、空状态统一；单页隐藏无用翻页按钮。
- 历史回查可返回来源、仅清除指标条件或清空全部筛选，三者语义区分。
- 单行双击只操作点击行，批量操作使用按钮，避免误处理其他已选号码。
- 结构页单行选中自动带入当前权重；恢复建议值只影响当前指标，不影响其他权重或强度。
- 不改变已有导入方式、历史/收藏存储格式、启动方式和随机算法。
