# 大乐透随机工具

独立的 Windows Python 桌面工具，默认无需历史数据即可点击 **生成号码**。包含随机选号、历史查询、统计分析、结构权重四个工作区。

## 启动与更新

- 安装带 Tcl/Tk 的 Python 3.10 或更高版本，双击 `启动.cmd`。通过隐藏启动器运行 `pythonw.exe`，没有常驻 CMD；也可直接双击 `scripts/launch.vbs`。
- 首次启动在本工具 `.venv` 中检查并安装 openpyxl、xlrd，可能需要等待。后续优先使用已记录的 Python 路径；启动失败会提示日志位置。移动工具或 Python 路径失效后自动重新检查。
- Windows 禁用 Script Host 时运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start.ps1`；排错可运行 `py -3 .\main.py`。
- 双击 `拉取更新.cmd`，通过整个仓库的 `git pull --ff-only` 更新当前分支上游。不会切换分支、强制重置或覆盖本地修改；其他工具的本地修改也可能阻止更新。更新成功后重启工具。ZIP 下载版没有 Git 元数据，不能直接拉取。

## 四个工作区

| 工作区 | 主要操作 |
| --- | --- |
| 随机选号 | 选模式和数量 → 按需展开固定/排除或跨区设置 → 生成 → 复制、导出、收藏 |
| 历史查询 | 选全部/50/100/自定义期数 → 输入号码或期号 → 查看、复制、导出匹配记录 |
| 统计分析 | 选近50/100/全部 → 看统计表、冷热号或频次图 → 双击次数回查 |
| 结构权重 | 选期数并统计 → 按指标组查看分布 → 应用权重/强度 → 去随机选号 |

顶部统一导入历史、更新开奖数据、查看校验明细，并显示最新期号与有效/无效/重复记录数。每页仍保留自己的用途和数据范围；统计分析的范围不修改选号所用的结构配置。

### 随机选号与收藏

- 一次 1–10000 组，前区 5–35 个、后区 2–12 个，支持本批完整组合不重复。
- 固定/排除输入可留空，多个号码用空格或逗号分隔。收起输入区仍保留并执行条件，下方摘要显示当前限制。参数过长时在参数区滚动，不挤占结果列表。
- 本批号码与我的收藏在结果区切换，不再各占半屏；生成完成自动回到本批号码。支持 Ctrl/Shift 多选、Ctrl+A 当前页全选、Ctrl+C 复制。表头点击排序，显示排序方向与选中条数；每页250条，仅多页时显示翻页按钮。
- 收藏去重并立即保存。双击只收藏/移除实际点击的一行；批量操作使用“收藏选中/移除选中”。导出全部指当前结果标签内的全部号码，不限当前页。
- 固定号码只约束选号，不是正式胆拖票型。金额按普通单式/复式 `C(前区数量,5) × C(后区数量,2)` 逐组计算；基本每注2元，含追加每注3元。不同组可能覆盖相同基本注，金额不隐式合并。工具不购买或提交投注。

### 三种模式与候选缓存

1. **均匀随机**：使用 `SystemRandom`，在合法组合空间中等概率抽取；固定/排除后只在剩余空间抽取。批内去重通过无放回抽取组合编号实现。历史数据和结构权重不影响本模式。
2. **历史频率加权**：使用结构权重页已应用窗口的号码出现次数+1。区内候选集合的相对权重为可选号权重乘积，由动态规划实现区内不重复选号。
3. **历史结构加权**：前区限5个，后区可为2–12个。前区按启用指标的归一化类别权重及指标强度计算加权几何平均；后区按所选窗口内的号码频次+1抽样。所有结构指标关闭时，前区结构不再偏置。

历史加权没有数据时明确报错。权重是相对偏好，不是最终生成比例或下期中奖概率；不同结构互相约束。小候选空间全量加权无放回，大空间采用有限重采样；无法凑齐请求数量时明确报错并保留上次完整结果。

结构模式首次计算有限前区候选（无限制时324632组），同一配置下复用最近一份完整候选缓存。窗口/实际历史/权重/强度/前区固定排除变化时重算；只改组数、批内去重或后区条件无需重算前区。每次仍重新抽样，缓存不保存随机结果。取消/失败不覆盖完整缓存，关闭程序释放缓存。界面主线程之外最多一个后台任务线程。

### 历史结构权重与跨区联动

最近期数预设50、100、全部，也可输入自定义正整数。**改期数后需点击“统计并自动填入权重”或按回车应用**；单纯切换预设不会抹掉手动调整。尚未应用的期数会明确提示，历史加权生成会阻止使用未提交配置。重新统计或更换历史数据将恢复全部建议权重；当前手动配置不跨重启保存。

| 指标组 | 细分内容 |
| --- | --- |
| 差值 | C1–C4相邻差，各1–31类别 |
| 连号 | 七类连续段形态、最长连号 |
| 空区 | 空区数量、五个分区各自空/非空 |
| 跨区 | 相邻差值>7的最大跨区、起始跨区 |
| 中间覆盖 | 差值>10跨过的五个中间分区 |

每个指标显示历史次数、实际期数、历史占比、建议权重、当前权重；数值型指标显示均值。均值不直接替代分布。建议权重为 `(次数+1)/(实际期数+类别数) × 100`，加1平滑避免近期未出现的类别被自动禁用。当前权重可设0–100，0排除；指标强度0–10，0关闭。选一行自动带入当前权重，可批量编辑选中的类别。“恢复本指标建议权重”只恢复当前指标的权重，保留其他指标与强度。

最长连号与连号形态、空区数量与各区空区相关，默认关闭最长连号和空区数量的强度，避免重复强调；可自行开启。指标定义不同，不删除或合并历史次数。

选号页选择结构模式后可勾选“自定义跨区权重”。它是同一结构配置的快捷编辑入口，有历史配置后即双向同步，不维护第二份独立权重。保留“一键填入”：默认取结构页当前已应用值，也可选50/100/全部或自定义期数后填入；重新选期会重算结构页所有指标并恢复建议权重，随后自动跟随结构页。非法或未完成输入不覆盖有效配置，生成时仍校验。跨区权重只参与一次评分，强度沿用结构页。

### 统计、冷热号与历史回查

统计分析主范围默认全部，可一键切换近50期、近100期。统计表次数/基数/百分比、频次图、导出与双击回查使用同一范围。类别选择用于筛表，导出包含当前范围内全部统计类别。

冷热号默认**跟随统计范围**，同时可选近50/100期进行独立对比。面板显示“跟随主范围”或“独立对比”、实际记录数及起止期号；主范围变化不会覆盖主动选定的独立对比范围。选回“跟随统计范围”立即同步。双击冷热号按它自己当前显示的范围回查。

前后区分别列出全部号码（包含零次数）、次数、期数占比和冷热状态。高于本区平均次数为热号（红），低于为冷号（蓝），相等持平；前区均值 `记录数×5÷35`，后区 `记录数×2÷12`。频次图是同一统计数据的图形视图，保留前区、后区次数及后区组合TOP30。

双击统计或结构行跳转历史查询，保留实际展示范围与指标，清除旧搜索文字。可以继续叠加号码/期号与期数筛选；“清除统计条件”只移除指标条件，“清空筛选”恢复全部范围并清空搜索，“返回统计来源”回到原分析页。历史来源行号和工作表默认收起，可勾选“显示来源列”；复制、导出始终保留这些信息。

查询支持号码包含全部/包含任意/连续位置，以及期号完全一致/前缀/后三位；连续位置不跨前后区。结果保留匹配说明及每期贡献次数。分区号码频率一期可能贡献多个号码，因此次数可能大于匹配期数；零次数也可回查为空结果。双击表头或空白不触发。

### 统计口径与去重

- 百分比 = 次数 ÷ 统计基数 × 100%。期数占比以有效记录数为基数；前区号码频率及分区频率以记录数×5为基数，后区号码频率以记录数×2为基数。前区期数占比合计500%、后区200%正常。
- 五分区：01–07、08–14、15–21、22–28、29–35。空区指未含该分区号码；中间覆盖指相邻差值>10跨过的中间区，定义不同。
- 最大跨区只看相邻差>7的间隔，取两端分区差的最大值，没有为0；起始跨区为最小号码所在分区减1。C1–C4为排序后的四个相邻差值。
- 最长连号分类互斥，“至少N连号”可重叠；连号形态如2+2+1表示两组二连号和一个单号。
- 近50/100期和结构窗口按数字期号排序、同一期去重后取最近N期，不足时使用实际样本。无期号按文件末尾记录；部分期号缺失或同一期号码冲突会拒绝近期计算。
- 普通统计、冷热号和历史查询的**全部范围保留导入重复记录**。结构权重的全部窗口仍按期号去重。页面显示实际样本口径，回查与显示次数保持一致。

## 历史数据与在线更新

支持 TXT、CSV、TSV、XLS、XLSX，也兼容误拼的 `.xlxs`。Excel 无需安装 Office。文本每行可以是7个号码，或期号+7个号码，也支持前后区用 `|`、中文标签分隔。示例仅表示格式：

```text
01 03 15 22 35 01 12
2026001 01 03 15 22 35 01 12
01,03,15,22,35,01,12
01 03 15 22 35 | 01 12
```

- 文本支持UTF-8/BOM、GB18030、带BOM的UTF-16。空行和 `#` 注释忽略；不合法的整行不计入统计，保留原因与原文。
- 前区1–35、后区1–12，区内唯一，前后区可同号；历史记录必须5+2，按数值升序归一化。
- 普通Excel按所有工作表的7号码列或期号+7号码列严格读取，也可在单元格内用空格分隔号码；整数数值和文本均可。未识别的多余列/缺失值/错误值/布尔值列为无效行。XLSX不导入公式，XLS读取已有公式缓存，不计算公式。
- 已适配上传的 `dlt.xls` 开奖报表，按明确表头定位期号、前后区，支持前置空列、分散表头、日期和奖金附加列、横向重复数据。每行只提取一组开奖，不重复计入；不需要改原文件。普通CSV不自动猜测日期/奖金等附加列。
- 手工导入重复记录保留并计数，不同期号同号码是不同记录。请在校验明细检查异常。生成的5+2 TXT可重新导入，复式结果和统计报表不能当作原始历史导入。

点击顶部“更新开奖数据”，后台从 `http://www.17500.cn/getData/dlt.TXT` 下载文本；无需Excel或宏，启动不联网。最新期号取决于第三方来源发布时间。同一期相同号码仅计一次，冲突、下载缺期、超时、解析失败或取消时保留原数据并提示原因。

导入与更新完成后共享给所有页面，原子保存到 `user_data/history.json`，下次先显示窗口再后台恢复。导入和更新失败保留上次完整数据及选号结果。更换数据时会清除历史查询的旧筛选，并重建结构建议权重。

## 源码与验证

收藏、历史快照、日志仅在本工具 `user_data`，Git忽略；不要放在无写权限的目录。收藏采用临时文件+原子替换，失败不先更新界面，损坏文件不被空收藏覆盖。

- `main.py` / `lottery/bootstrap.py`：启动、DPI与日志。
- `lottery/core`：随机、结构、统计、查询和缓存；`lottery/data`：导入、导出与存储。
- `lottery/ui`：各工作区、共用表格、主题、表单布局及后台任务。
- `scripts`：Windows启动、更新与验证；`tests`：核心、Tcl状态及真实Tk窗口测试。
- `docs/源码分析.md`：原9个脚本的整合；`docs/UI优化.md`：重叠功能分析与交互设计；`docs/验证记录.md`：执行结果与限制。

在工具目录运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\verify.ps1`。编译检查不等于运行验证；无显示服务时真实Tk测试明确跳过。Windows启动器、DPI缩放和拉取更新需实机验证。
