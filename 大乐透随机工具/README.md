# 大乐透随机工具

独立的 Windows Python 桌面工具，默认无需历史数据即可点击 **生成号码**。包含随机选号、历史查询、统计分析、结构权重四个工作区。

## 启动与更新

- 安装带 Tcl/Tk 的 Python 3.10 或更高版本，双击 `启动.cmd`。通过隐藏启动器运行 `pythonw.exe`，没有常驻 CMD；也可直接双击 `scripts/launch.vbs`。
- 首次启动在本工具 `.venv` 中检查并安装 openpyxl、xlrd，可能需要等待。后续优先使用已记录的 Python 路径；启动失败会提示日志位置。移动工具或 Python 路径失效后自动重新检查。
- Windows 禁用 Script Host 时运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start.ps1`；排错可运行 `py -3 .\main.py`。
- 双击 `拉取更新.cmd`，从 `origin` 获取更新并仅允许快进当前分支。Git 会保留与更新无冲突的本地改动；如果新版会覆盖本地修改或文件（包括被忽略的文件），或者分支已分叉，窗口会停留并显示原因。更新成功后重启工具。ZIP 下载版没有 Git 元数据，不能直接拉取。
- 旧版脚本若仍提示 `There are local changes`，先在工具目录用 PowerShell 执行一次 `git pull --ff-only --no-rebase` 拉到新版；之后即可双击更新。

## 四个工作区

| 工作区 | 主要操作 |
| --- | --- |
| 随机选号 | 选模式 → 设置参数 → 生成 → 复制、导出、收藏；双击记录号码并按期对奖 |
| 历史查询 | 选全部/50/100/自定义期数 → 输入号码或期号 → 查看、复制、导出匹配记录 |
| 统计分析 | 选近50/100/全部查看常规统计；下方可单独计算下期条件频次 |
| 结构权重 | 进阶用法：选期数并填入建议权重 → 选择参与抽取的细分指标 → 开始抽取 |

界面沿用 Windows 原生控件，局部调整尺寸和间距；底部操作区预留空间，统计上下分隔线可拖动调整。

顶部统一导入历史、更新开奖数据、查看校验明细，并显示最新期号与有效/无效/重复记录数。每页仍保留自己的用途和数据范围；统计分析的范围不修改选号所用的结构配置。

### 随机选号与收藏

- 普通批量模式一次 1–10000 组，前区 5–35 个、后区 2–12 个，支持本批完整组合不重复；同星期 / 历年同期一次生成一套三档。
- 固定/排除输入可留空，多个号码用空格或逗号分隔。收起输入区仍保留并执行条件，下方摘要显示当前限制。参数过长时在参数区滚动，不挤占结果列表。
- 本批号码、我的收藏、选号记录 / 对奖在结果区切换；生成完成自动回到本批号码。支持 Ctrl/Shift 多选、Ctrl+A 当前页全选、Ctrl+C 复制。表头点击排序，显示排序方向与选中条数；每页250条，仅多页时显示翻页按钮。
- 收藏去重并立即保存。「我的收藏」显示首次收藏的北京时间，默认最新在上；点击时间表头可切换排序。旧条目保留号码并标为「日期未记录」，列在已知时间之后。要删除收藏，选中号码后点“移除选中”。复制、导出仍使用号码格式，导出全部不限当前页。
- 固定号码只约束选号，不是正式胆拖票型。金额按普通单式/复式 `C(前区数量,5) × C(后区数量,2)` 逐组计算；基本每注2元，含追加每注3元。不同组可能覆盖相同基本注，金额不隐式合并。工具不购买或提交投注。

### 选号记录与对奖

- 在“我的收藏”单选或用 Ctrl / Shift 多选，点“记录选号”即可整批保存并跳到“选号记录 / 对奖”，定位本批。在收藏或本批号码双击仍只记录点击的一组；本批号码双击还会顺便收藏。若筛选隐藏了所选记录，会切回“全部记录”。
- 预计开奖日按这次记录的北京时间计算，收藏时间不变。仅点击“收藏选中”仍是普通收藏。同一预计期的相同号码只记录一次；不同期可再次记录。记录保存在 `user_data/picks.json`，重启后还在。
- 预计开奖日在周一、周三、周六选出：开奖日北京时间 21:00 前归当天，21:00 起归下一预计开奖日。按[体彩时间公告](https://m.lottery.gov.cn/xxgk/tzggz/20221220/10027143.html)，21:00 是停售、21:25 是开奖，休市除外。
- 在“选号记录 / 对奖”可单选或多选。「更正期号」将选中记录统一改为输入的票面期号，留空恢复各自的自动归期。「删除选中」确认后只删除本次选中的对奖记录，原收藏不会改变。
- 开奖后点“更新开奖数据”，选中记录查看命中和下方奖金。第26014期起按[七奖级规则](https://m.lottery.gov.cn/ksjz/m/yxgz_dlt/)计算普通单式/复式注数；更早的期次只对照号码。金额按基本投注 1 倍、税前计算；不含追加、额外派奖和票面倍数。多选时合计已知金额，缺失部分单独提示。
- 中奖记录的单注奖金按期从一定牛的公开开奖详情查询，校验期号、号码和日期后才用来计算。选中涉及一期的中奖记录会自动查询；跨期可点“查询奖金”一次获取。查询失败或没有公布金额时保留未核算状态。
- 自动匹配使用开奖数据的实际日期；缺日期、休市、日期未找到或记录冲突时不会把下一期开奖结果套进来。旧版历史快照可读，在线更新后会补齐开奖日期；已识别的 Excel 开奖报表也会保留可识别日期。

### 选号模式

1. **均匀随机**：使用 `SystemRandom`，在合法组合空间中等概率抽取；固定/排除后只在剩余空间抽取。批内去重通过无放回抽取组合编号实现。历史数据和结构权重不影响本模式。
2. **历史频率加权**：使用结构权重页已应用窗口的号码出现次数+1。区内候选集合的相对权重为可选号权重乘积，由动态规划实现区内不重复选号。
3. **同星期 / 历年同期**：默认取目标期之前最近9次同星期开奖及过去9年同一期序，合并并按期去重。期号留空时，用最新已载入的日期估算下次常规开奖；休市或需要回查时可手填期号，必要时选星期。任一窗口填0可跳过。
   按龙头（前区最小号）、凤尾（最大号）、前区奇偶比与后区跨度的历史分布加权，沿用下文的理论占比校准。先抽一注5+2，再按合法组合中的号码加权出现量扩成9+3和15+5，三档逐级包含。三档分别显示注数，固定或排除的号码会在所有档位生效。该模式复用帖里可以核对的结构，作者手工选胆和杀号不参与计算。
   9/9 用于复现原帖的取样方式；对 1,567 期的逐期回测没有发现比均匀随机更稳定的命中优势。比较方法见[验证记录](docs/验证记录.md)。
4. **下期条件频次**：选择参照期（留空为最新）和回看窗口。前区只用条件频次汇总票数+1，后区只用参照期完整对子开出后各号的次数+1，两区可分别勾选，未勾选的一侧等权。“查看分析”打开同一参照期和范围的报表。两种帖子模式各自独立，不套用进阶结构权重。

历史加权没有数据时明确报错。权重是相对偏好，不是最终生成比例或下期中奖概率；不同结构互相约束。小候选空间全量加权无放回，大空间采用有限重采样；无法凑齐请求数量时明确报错并保留上次完整结果。

### 历史结构权重与跨区联动

最近期数预设50、100、全部，也可输入自定义正整数。**改期数后需点击“统计并自动填入权重”或按回车应用**；单纯切换预设不会抹掉手动调整。尚未应用的期数会明确提示，历史加权生成会阻止使用未提交配置。重新统计或更换历史数据将恢复全部建议权重；当前手动配置不跨重启保存。

「历史结构加权」收在进阶入口。到「结构权重」页点击 **应用到选号页** 后才会在随机首页选中该模式。在 **本次加权指标** 中选择指标组和细分项：点击 **只用这一项** 可立即替换现有组合，勾选 **用于抽取** 可把当前项加入已有组合，取消勾选即可移除。开始时默认不选任何指标；调权重、统计填入或跨区一键填入都不会替你选中。两页共用选择。重新统计会重置手调权重，保留已选清单。

历史结构加权前区限5个，后区可为2–12个。只使用本次所选指标。单项直接使用该项权重；多项把各项权重的强度次幂相乘。零权重只在对应指标被选中时排除候选，没有选指标的一侧等权。同一配置下复用最近一份完整的前区候选缓存；所用窗口、已选前区指标权重/强度、跨期参照或前区固定排除变化时重算。只改组数、去重、未选指标或后区设置无需重算前区。每次仍重新抽样。界面主线程之外最多一个后台任务线程。

本页下方的 **“按当前权重抽取”** 可填组数、后区数量，并展开固定/排除号码；这些条件与随机选号页共用。点击 **“开始抽取”** 使用已填入的期数及当前权重（含手动调整），按历史结构加权抽取，前区为5个。完成后在“本批号码”显示结果，状态栏显示实际样本数和起止期号；无期号的文件按记录顺序。若希望先看选号页设置，点击“应用到选号页”，会自动选好结构加权模式。

| 指标组 | 细分内容 |
| --- | --- |
| 差值 | C1–C4相邻差，各1–31类别 |
| 连号 | 七类连续段形态、最长连号 |
| 空区 | 空区数量、五个分区各自空/非空 |
| 跨区 | 相邻差值>7的最大跨区、起始跨区 |
| 中间覆盖 | 差值>10跨过的五个中间分区 |
| 前区形态 | 奇偶比、小大比、012路比、质合比、同尾组数 |
| 前区数值 | 和值（15–165）、跨度（4–34）、AC值 |
| 前区区间 | 三区比（01–12 / 13–24 / 25–35）、五区比（每区7号） |
| 后区结构 | 奇偶比、小大比、012路比、和值、跨度、同尾组数、质合比、三区比（每区4号） |
| 跨期重邻孤 | 前后区各自的重号、邻号、孤号数 |
| 遗漏结构 | 前后区各自按开奖前遗漏0、1–5、6–11、12期以上分档的选号个数 |
| 前区定位 / 后区定位 | 排序后的前区第1–5位、后区第1–2位，逐位置统计和加权 |

每个指标显示历史次数、有效样本、历史占比、建议权重、当前权重；数值型指标显示均值，比例指标显示各分量平均个数。均值只作参考，双击类别可回查同窗口的真实开奖。原指标建议权重保持 `(次数+1)/(有效样本+类别数) × 100`。当前权重可设0–100；指标强度默认1，可调0–10，已选但为0时提示调整或取消选择。选一行自动带入当前权重，可批量编辑选中的类别。“恢复本指标建议权重”只恢复该项类别权重。

走势图指标显示“理论占比”，即没有固定、排除等条件时，该结构在均匀组合中的占比；跨期项按有效历史参照的理论占比取均值。建议权重用 `50 × 限幅[(历史次数+5)/(有效样本×理论占比+5), 0.5, 2]`，历史与理论接近时约为50，少样本偏差做平滑。跨度和四个相邻差值、最长连号和连号形态、空区数量和各区空区有关联，可按需求单独选，避免重复强调。

小大比为“小:大”（前区 01–17 / 18–35，后区 01–06 / 07–12）；012路比按除3余数计数。质合比为“质:合:01”，同尾组数按重复出现的不同个位数计组，前区AC值为所有两两绝对差去重后的个数减4（后区仅两码，AC恒为0，不额外列项）。

重号是与上一期同区相同；邻号差1且本身不是重号；孤号是两者之外的号码。统计只用能核实连续的期号，窗口首期可以用窗外参照；缺期不拼接，跨年需要相邻常规开奖日佐证。遗漏结构还需要至少连续12期参照。抽取参照最新已载入期，样本或连续期资料不足时会明确提示。后区复式在每个二码对子内按所选项相乘，再取各对子评分的几何平均；任一对子被选中指标排除时整组排除。

口径参考[体彩游戏规则](https://m.lottery.gov.cn/ksjz/m/yxgz_dlt/)、中彩网的[奇偶分布](https://tubiao.zhcw.com/tubiao/dlt/dltInc/dlt_jiOuFenBuTuAsc.html)、[大小分布](https://tubiao.zhcw.com/tubiao/dlt/dltJsp/dlt_lnty_daXiaoFenBuTuAsc.jsp)与[和值分布](https://tubiao.zhcw.com/tubiao/dlt/dltJsp/dlt_qianQuHeZhiFenBuTuDesc.jsp)，以及彩之家的[历史特征表](https://chart.cpzj.com/dlt/zs_history.html)、[定位](https://chart.cpzj.com/dlt/zs_dwzs.html)和[遗漏明细](https://chart.cpzj.com/dlt/yl_qqcode.html)。这些指标描述历史或组合结构，不预测下一期。

选号页的“自定义跨区权重”双向同步同一配置。“一键填入”可取结构页当前值，也可选50/100/全部或自定义期数重算。不完整的输入不覆盖有效配置；只有选入本次抽取的跨区项才校验和参与评分。

### 统计、冷热号与历史回查

统计分析主范围默认全部，可一键切换近50期、近100期。统计表次数/基数/百分比、频次图、导出与双击回查使用同一范围。类别选择用于筛表，导出包含当前范围内全部统计类别。

冷热号默认**跟随统计范围**，同时可选近50/100期进行独立对比。面板显示“跟随主范围”或“独立对比”、实际记录数及起止期号；主范围变化不会覆盖主动选定的独立对比范围。选回“跟随统计范围”立即同步。双击冷热号按它自己当前显示的范围回查。

前后区分别列出全部号码（包含零次数）、次数、期数占比和冷热状态。高于本区平均次数为热号（红），低于为冷号（蓝），相等持平；前区均值 `记录数×5÷35`，后区 `记录数×2÷12`。频次图是同一统计数据的图形视图，保留前区、后区次数及后区组合TOP30。

下半区的「号码遗漏」显示前后区逐号当前遗漏、窗口内最大和平均已完成间隔、窗口次数、间隔样本数、最后出现期号。当前遗漏从最新连续开奖段计数；这一段未出现的号码只显示已知下限“≥”。最大和平均只用统计窗口中两次开出之间的完整间隔，不把断档当作未开。

「下期条件频次」使用独立窗口（全部、50、100或自定义）。对参照期前区五个号分别统计：该号开出后，有多少个已知的相邻下一期，以及下一期各号的出现次数和占有效下一期的比例。每个前区条件按次数取最多5个实际出现过的号码（同次数按号升序），每进一次 Top 5 记一票；可切换汇总和单号明细。后区按参照期两个号同时开出统计，不能只匹配其中一个。参照期本身可计入出现次数，没有可用下一期便不计入分母；跳过缺期，并且不使用参照期之后的数据。

双击统计或结构行跳转历史查询，保留实际展示范围与指标，清除旧搜索文字。可以继续叠加号码/期号与期数筛选；“清除统计条件”只移除指标条件，“清空筛选”恢复全部范围并清空搜索，“返回统计来源”回到原分析页。历史来源行号和工作表默认收起，可勾选“显示来源列”；复制、导出始终保留这些信息。

查询支持号码包含全部/包含任意/连续位置，以及期号完全一致/前缀/后三位；连续位置不跨前后区。历史查询表格底部可点“首页 / 尾页”跳到当前结果的第一或最后一页，保留筛选与排序。结果保留匹配说明及每期贡献次数。分区号码频率一期可能贡献多个号码，因此次数可能大于匹配期数；零次数也可回查为空结果。双击表头或空白不触发。

### 统计口径与去重

- 百分比 = 次数 ÷ 统计基数 × 100%。期数占比以有效记录数为基数；前区号码频率及分区频率以记录数×5为基数，后区号码频率以记录数×2为基数。前区期数占比合计500%、后区200%正常。
- 五分区：01–07、08–14、15–21、22–28、29–35。空区指未含该分区号码；中间覆盖指相邻差值>10跨过的中间区，定义不同。
- 最大跨区只看相邻差>7的间隔，取两端分区差的最大值，没有为0；起始跨区为最小号码所在分区减1。C1–C4为排序后的四个相邻差值。
- 最长连号分类互斥，“至少N连号”可重叠；连号形态如2+2+1表示两组二连号和一个单号。
- 近50/100期和结构窗口按数字期号排序、同一期去重后取最近N期，不足时使用实际样本。无期号按文件末尾记录；部分期号缺失或同一期号码冲突会拒绝近期计算。
- 普通统计、冷热号和历史查询的**全部范围保留导入重复记录**。结构权重的全部窗口仍按期号去重。页面显示实际样本口径，回查与显示次数保持一致。

支持 TXT、CSV、TSV、XLS、XLSX，也兼容误拼的 `.xlxs`。Excel 无需安装 Office。文本每行可以是7个号码，或期号+7个号码，也支持前后区用 `|`、中文标签分隔。示例仅表示格式：

```text
01 03 15 22 35 01 12
2026001 01 03 15 22 35 01 12
01,03,15,22,35,01,12
01 03 15 22 35 | 01 12
```

- 文本支持UTF-8/BOM、GB18030、带BOM的UTF-16。空行和 `#` 注释忽略；不合法的整行不计入统计，保留原因与原文。
- 前区1–35、后区1–12，区内唯一，前后区可同号；历史记录必须5+2，按数值升序归一化。
- 普通Excel按所有工作表的7号码列或期号+7号码列严格读取，也可在单元格内用空格分隔号码；整数数值和文本均可。未识别的多余列/缺失值/错误值/布尔值列为无效行。XLSX不导入公式，XLS读取已有公式缓存，不计算公式。
- 已适配上传的 `dlt.xls` 开奖报表，按明确表头定位期号、前后区，支持前置空列、分散表头、日期和奖金附加列、横向重复数据。每行只提取一组开奖，不重复计入；不需要改原文件。普通CSV不自动猜测日期/奖金等附加列。
- 手工导入重复记录保留并计数，不同期号同号码是不同记录。请在校验明细检查异常。生成的5+2 TXT可重新导入，复式结果和统计报表不能当作原始历史导入。

点击顶部“更新开奖数据”，后台从 `http://www.17500.cn/getData/dlt.TXT` 下载文本；无需Excel或宏，启动不联网。最新期号取决于第三方来源发布时间。同一期相同号码仅计一次，冲突、下载缺期、超时、解析失败或取消时保留原数据并提示原因。

导入与更新完成后共享给所有页面，原子保存到 `user_data/history.json`，下次先显示窗口再后台恢复。导入和更新失败保留上次完整数据及选号结果。更换数据时会清除历史查询的旧筛选，并重建结构建议权重。

## 源码与验证

收藏、选号记录、历史快照、日志仅在本工具 `user_data`，Git忽略；不要放在无写权限的目录。收藏和选号记录采用临时文件+原子替换，失败不先更新界面，损坏文件不被空记录覆盖。

- `main.py` / `lottery/bootstrap.py`：启动、DPI与日志。
- `lottery/core`：随机、结构、统计、查询和缓存；`lottery/data`：导入、导出与存储。
- `lottery/ui`：各工作区、共用表格、主题、表单布局及后台任务。
- `scripts`：Windows启动、更新与验证；`tests`：核心、Tcl状态及真实Tk窗口测试。
- `docs/源码分析.md`：原9个脚本的整合；`docs/UI优化.md`：重叠功能分析与交互设计；`docs/验证记录.md`：执行结果与限制。

在工具目录运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\verify.ps1`。编译检查不等于运行验证；无显示服务时真实Tk测试明确跳过。Windows启动器、DPI缩放和拉取更新需实机验证。
