# 大乐透随机工具

把上传的 9 个 Python 程序整合为一个独立的 Windows 桌面工具。默认打开后直接点击 **重新随机**，无需导入数据或填写参数。仅使用 Python 标准库，不需要安装 numpy、matplotlib 或其他 pip 依赖。

## 启动与更新

- 安装带 Tcl/Tk 的 Python 3.10 或更高版本。
- 双击本目录的 `启动.cmd`：经隐藏的启动器运行 `pythonw.exe`，启动后没有常驻 CMD。也可双击 `scripts/launch.vbs`，避免 CMD 短暂出现。
- 若 Windows 禁用了 Windows Script Host，在本目录用 PowerShell 运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start.ps1
```

- 排查启动问题时可在 PowerShell 运行 `py -3 .\main.py`。
- 双击 `拉取更新.cmd` 更新**当前分支的上游**，成功后自动退出，失败保留窗口。不会强制重置、切换分支或覆盖本地修改。更新成功后重启工具。
- 更新通过整个 `pyt1` 仓库的 `git pull --ff-only` 完成；其他工具若有本地修改会阻止更新。下载 ZIP 不含 Git 元数据，不能直接 `git pull`。

## 功能

| 页面 | 功能 |
| --- | --- |
| 随机选号 | 一次 1–10000 组；前区 5–35、后区 2–12；固定号码、排除号码；批内完整组合去重；取消任务 |
| 我的收藏 | 选中或双击收藏；自动去除重复收藏；批量移除；立即保存，下次打开恢复 |
| 结果操作 | Ctrl/Shift 多选、Ctrl+A 当前页全选、Ctrl+C 复制；导出全部；每页 250 行，分页不限制生成总量 |
| 历史查询 | 期号完全/前缀/后三位；号码包含全部/包含任意/连续位置；前区、后区或全部；匹配位置与占比 |
| 统计分析 | 前后区次数、号码频率、期数占比、后区组合、五分区频率、空区、中间断区、最大跨区、起始跨区、连号、C1–C4 差值 |
| 图表与导出 | 前区、后区次数柱状图，后区组合 TOP30；完整统计 CSV；匹配记录 CSV；无效行明细与 CSV |

固定号码只约束每一组随机结果，不是正式“胆拖投注”的票型。金额始终按输出的普通单式/复式计算：`C(前区数量, 5) × C(后区数量, 2)` 注。基本每注 2 元，含追加每注 3 元；多组复式可能覆盖相同基本注，金额是逐组之和，不做隐式合并。界面不购买、不提交任何投注。

金额依据：[中国体育彩票超级大乐透游戏规则](https://m.lottery.gov.cn/ksjz/m/yxgz_dlt/)，2026-10-21 查阅。没有硬编码旧版奖级、奖池或中奖金额。

## 三种随机模式

1. **均匀随机（默认）**：系统提供的随机源 `SystemRandom`，在符合固定/排除条件的组合空间中等概率抽取。批内去重直接无放回抽取组合编号，再还原号码，不靠碰运气重试。导入历史数据不会改变该模式。程序不宣称使用物理“真随机”。
2. **历史频率加权**：只使用本次导入数据。每个号码的权重为出现次数加 1；一个区内集合的相对权重是其中可选号码权重的乘积，用动态规划完成不重复选号。加 1 是明确的平滑规则，不是伪造历史次数；统计表仍展示原始真实次数。
3. **历史结构加权**：前区限 5 个号码，后区可为 2–12 个。遍历有限的前区候选空间（无固定/排除时 324632 组），按号码次数、四个相邻差值、最长连号及五区空/非空的平滑历史权重计算几何平均，再乘最大跨区和起始跨区权重。后区使用历史频率。可取消，不阻塞界面；每次生成重新计算候选，以保证参数变更立即生效。

结构模式默认跨区权重为该类别的历史出现次数加 1。勾选“自定义跨区权重”后，界面输入替换这两组默认权重：每类允许 0–100，0 排除，正数按比例参与抽样，不要求总和 100。**这是相对权重，不是最终输出比例或下一期的中奖概率。** 不同结构互相制约，无法把多个边际频率独立当成精确目标。

历史加权没有数据时明确报错，不偷偷退回均匀模式。小候选空间全量加权无放回抽样；大空间批内去重使用有上限的重采样。若权重集中到无法在上限内凑齐请求数量，会明确报错并保留上次完整结果。不会悄悄少生成、改条件或换算法。

## 历史数据

压缩包仅含 Python 源码，没有历史开奖文件。本工具不内置、不伪造、不自动联网抓取开奖数据；使用你自己导入的文件。

每行支持以下格式（下列仅为**格式示例，不是实际开奖数据**）：

```text
01 03 15 22 35 01 12
2026001 01 03 15 22 35 01 12
01,03,15,22,35,01,12
01 03 15 22 35 | 01 12
前区: 01 03 15 22 35 后区: 01 12
```

- 支持 TXT、CSV、TSV；CSV 指 7 个号码列或期号加 7 个号码列，不支持任意网页导出的日期、奖金等额外列。表头作为无效行列出，不静默猜列。
- 支持 UTF-8/BOM、GB18030、带 BOM 的 UTF-16。
- 按整数统一校验前区 1–35、后区 1–12、区内号码唯一；前后区允许同号。
- 整行验证通过才计入统计；坏后区不会污染前区统计。自动按数值升序归一化。
- 空行和 `#` 注释忽略；无效行记录原始行号、原因和原文。
- 重复记录计数并**保留**，避免擅自删除用户的重复采样；不同期号的相同号码视为不同记录。要分析开奖历史时，请在校验明细核对重复数。
- 导入一次即共享给生成、查询和统计，不重复读取文件。重新打开应用需要重新导入历史文件，以免无提示使用旧历史。
- 文件读取/分析失败或取消时，保留上次成功导入的数据和已有生成结果。
- 生成的 5+2 TXT 可直接重新导入；复式结果不是历史 5+2 记录，不能作为历史数据导入。查询/统计导出是报表，不是原始开奖文件。

## 统计口径

- 前区号码频率：次数 / (有效记录数 × 5)，35 个号码合计 100%；后区号码频率分母为记录数 × 2。
- 期数占比：号码出现次数 / 有效记录数；前区所有号码相加为 500%，后区为 200%，这不是错误。
- 五区：01–07、08–14、15–21、22–28、29–35。
- 空区：整行未包含该分区号码。中间断区：相邻差值大于 10 时所跨过的中间区；二者分别统计。
- 最大跨区：仅考虑相邻差值大于 7 的间隔，取结束区减起始区的最大值，没有则为 0。
- 起始隐含跨区：最小号码所在区减 1；C1–C4 是排序后的四个相邻差值。
- 最长连号分类互斥；“至少 N 连号”可重叠，分别展示。

## 存储与源码

收藏和日志仅在本工具 `user_data` 文件夹，Git 自动忽略。写入收藏采用临时文件加原子替换；写入失败不先更新界面；损坏文件不会被空收藏覆盖。请把工具放在当前 Windows 账户有写权限的位置，不推荐 `Program Files`。

- `main.py` / `lottery/bootstrap.py`：入口、DPI、日志。
- `lottery/core`：模型、随机、结构、统计、查询。
- `lottery/data`：导入、导出、收藏存储。
- `lottery/ui`：表单、各页、表格、图表、后台任务。
- `scripts`：Windows 隐藏启动、更新、验证。
- `tests`：核心及真实 Tk 集成测试；没有桌面时明确跳过界面测试。
- `docs/源码分析.md`：原 9 个脚本的逐项分析和整合对应关系。
- `docs/验证记录.md`：已执行与未执行的验证，分开记录。

## 验证

在本工具目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\verify.ps1
```

这会进行 Python 编译检查和自动测试。在正常 Windows 桌面，Tk 集成测试会实际创建窗口，验证生成、复制、收藏、导入、查询、分页与取消；没有显示环境则输出明确的 skipped。Windows 启动器、窗口缩放和 Git 更新仍需按验证记录手动检查。
