# 六爻摇卦

由上传的六爻脚本整理而来，保留三枚铜钱起卦、六爻动画、本卦、之卦和符号说明。工具独立运行，不读取其他小工具的数据。

## 启动

Windows 安装 Python 3.10 或更新版本，并保留安装器中的 Tcl/Tk、IDLE 和 Python Launcher 选项。无需安装第三方库。

双击本文件夹中的 **`启动.bat`**：启动窗口后 CMD 自动退出，程序由 `pythonw.exe` 独立运行，不需要保留终端。也可在 `.pyw` 已正确关联 Python 的电脑上双击 `app.pyw`。如果启动或运行发生异常，会弹出错误信息，便于截图排查。

macOS / Linux（需可用的 Tk 图形环境），或需要在终端排查问题时：

```bash
python app.py
```

## 更新

关闭工具后，双击本文件夹中的 **`拉取更新.cmd`**。

- 在 Git 克隆的 `pyt1` 仓库内执行 `git pull --ff-only --no-rebase`，更新整个仓库。
- 更新成功或已经是最新版：CMD 自动关闭。
- 更新失败、未安装 Git 或文件夹不是 Git 工作副本：保留窗口显示原因，按任意键后退出。
- 不强制覆盖本地修改、不自动暂存或合并。下载 ZIP 得到的文件夹不能用 `git pull` 更新。
- 更新的是下次启动加载的代码，已打开的程序需要重启。

## 使用与规则

点击“开始摇卦”，待六个爻停止后查看左右两卦。每轮结束可再次起卦。爻位自下而上为初爻至上爻。

本卦、之卦标题右侧分别有 **“复制本卦”**、**“复制之卦”** 按钮。摇卦完成后可独立复制对应卦象，文字按界面从上爻到初爻排列。本卦包含爻名、点数及动静状态；之卦包含变化后的阴阳爻。成功后按钮显示“已复制”。尚未起卦或正在重新摇卦时，两个复制按钮均不可用。

三枚铜钱分别独立、等概率取 2 或 3，合计 6、7、8、9 分别对应老阴、少阳、少阴、老阳，概率为 1/8、3/8、3/8、1/8。老阴变阳、老阳变阴，静爻不变。此版本显示爻象及变化，不包含纳甲干支、六亲、世应或六十四卦名排盘。

## 代码结构

- `app.py` / `app.pyw`：入口。
- `liuyao_tool/application.py`：应用组装。
- `liuyao_tool/domain/`：爻与变卦规则。
- `liuyao_tool/domain/text.py`：本卦和之卦的复制文本格式。
- `liuyao_tool/generation/`：铜钱随机抽取。
- `liuyao_tool/ui/`：界面布局、显示状态与动画控制。
- `liuyao_tool/startup/`：启动和异常显示。
- `tests/`：随机规则、变卦和生命周期验证。

在本工具目录运行：

```bash
python -m unittest discover -s tests -v
```
