# 原文资料与现代参考的来源

## 原文

原文取自维基文库《周易》六十四卦各子页中的卦辞、六爻爻辞、大象，以及乾、坤的用九、用六。保留繁体、异体字；来源中以模板标出的异文转为括号内的“异文”说明。卦名和界面标签使用简体，原文不自动转换。

- 总目录与卦象对照：https://zh.wikisource.org/wiki/周易
- 转录贡献者：维基文库贡献者；各页贡献历史可由对应原文页面进入。
- 每卦 JSON 的 `source` 保存原文页面、获取时的修订编号及固定版本链接。此次整理日期：2026-10-19。
- 古籍原文本身属于公有领域。所采用的维基文库转录整理含标点、异文等编辑信息；本目录下 `hexagrams/*.json` 作为整理资料按 CC BY-SA 4.0 提供：https://creativecommons.org/licenses/by-sa/4.0/deed.zh-hans 。修改包括摘录、去除网页标记、整理结构、简体卦名，以及新增 `editorial` 参考字段。此资料许可不改变程序源码的许可。

## 现代参考

`editorial` 字段是本工具编写的主题概括、推进角度和谨慎角度；爻位辅助提问、主题匹配与条件变化提示也由本工具编写。它们不是古籍原文、学者译注或唯一标准卦解。

第一版采用卦辞与爻辞阅读方式；不包含纳甲干支、六亲、世应、月建日辰或应期推断，也不自称完整的六爻纳甲断卦。对于多动爻，全部并列显示，不采用某一门派的唯一取用规则。只有本卦为乾或坤且六爻皆动时，另列相应的用九或用六作为补充原文。

原文与解读均随工具本地提供，运行不联网；主题仅按问题关键词辅助识别，不提供自由语义推理，不补造事实或预测概率。用户输入的问题与背景只保留在当前窗口内，不自动写入文件。
