# 字体批量改名

根据字体 name 表批量调整磁盘文件名，不修改字体内部名称、字形或字体文件内容。

## Windows 启动

1. 安装 Python 3.10 或以上版本，包含 Tcl/Tk 和 Python Launcher。
2. 首次运行双击 `install.bat`，在本工具目录建立独立 `.venv` 并安装依赖（首次安装需要网络）。
3. 双击 `启动.bat`。启动脚本随即退出，工具通过 `pythonw.exe` 独立运行，不保留 CMD 窗口；启动异常会弹窗显示。

也可自行安装 `requirements.txt` 后运行 `python app.py`；原入口 `字体批量改名_GUI.py` 继续可用。

## 拉取更新

双击本目录的 `拉取更新.cmd`：成功（包括已是最新）自动关闭，失败保留窗口和 Git 报错。需安装 Git，且目录来自 Git 克隆；ZIP 解压目录无法拉取。更新作用于整个仓库，使用 `git pull --ff-only`，不会自动丢弃本地修改或自动合并分叉。更新前关闭工具，完成后重新启动。依赖发生变化时重新运行 `install.bat`。

## 使用

选择文件夹和格式 → 扫描并预览 → 确认新文件名 → 执行改名。

预览结果顶部可筛选「全部 / 跳过 / 将重命名」，显示当前项数与总项数。执行改名仅处理当前筛选结果中的待改名项；选择「跳过」时禁用执行按钮。CSV 导出仍包含完整计划；执行完成后可切回「全部」查看成功和错误记录。

- 保留原版 TTF、OTF、WOFF、WOFF2、DFONT 格式选项；实际可读性取决于字体内容。暂不新增 TTC/OTC 集合支持。
- 支持子目录、扩展名小写、空格替换下划线、重名加数字后缀或跳过。
- 默认依次尝试 NameID 4、1、16、6；每个 NameID 内依次尝试简中、繁中台湾、繁中香港、英文等语言。这里是 **NameID 优先，其次语言**，保留原版规则。
- 扫描不改文件；执行使用临时文件名分两阶段移动。规划会保守地避让其他现有文件名，即使该文件也准备改名。
- 忙碌期间不能清空结果或关闭窗口；执行使用扫描时的目录与计划，修改输入框不会改变已有预览。
- 自动 CSV 日志使用 UTF-8 BOM，保存到扫描目录；保存失败会提示，可再次导出。文件移动与日志写入不是原子事务。
- 改名失败尝试还原该项；无法还原时，说明列/CSV 中记录临时文件完整路径。不要删除这些临时文件。断电或强制结束进程不提供自动恢复。
- Windows 文件被占用、权限不足等错误会显示在结果中。本工具不处理已安装字体的注册表或安装/卸载。

## 代码组织

- `app.py`、`字体批量改名_GUI.py`：启动入口。
- `font_renamer/config.py`：默认规则与状态。
- `font_renamer/core/`：数据模型、名称清理、字体读取、扫描规划、执行与失败回退。
- `font_renamer/storage/`：CSV 输出。
- `font_renamer/ui/`：窗口布局、交互与后台任务、Windows DPI。
- `tests/`：真实最小字体 name 表和临时目录文件操作测试。

## 本机打包

安装依赖后双击 `build.bat`，生成 `dist/FontBatchRenamer.exe`。打包脚本须在 Windows 上执行；此提交未生成或验证 Windows EXE。

在本工具目录运行：

```powershell
python -m unittest discover -s tests -v
```

自动化覆盖中文名称读取、文件内容保持、重名/同名目录、大小写改名、路径交换、目标临时出现、失败回退、保留临时文件提示、损坏字体与 CSV。Windows 实际窗口、文件占用和 EXE 需要本机实测。

## 重复字体清理

首次更新后重新运行 `install.bat` 安装 Send2Trash 和 Windows 回收站组件 pywin32，再启动工具。
选择字体目录、格式与是否包含子目录，先点击主界面「扫描并预览」，再点击「重复字体清理」。按文件大小分组后计算完整文件 SHA-256，只有字节内容完全一致才列为重复；仅字体名称相同、不同版本或不同封装的字体不会合并。扫描不改动文件。

每组按完整路径排序保留第一份，预览同时显示保留路径和重复路径；点击第一列取消勾选，或全选/取消全选。确认后仅将勾选文件移入 Windows 回收站。操作前再次校验两份内容，保留项丢失或内容变化时拒绝清理。权限、占用或回收站失败显示在说明列，不降级为永久删除。网络盘等位置可能不支持回收站，此时保留文件并报告失败。

清理任务在后台进行，期间不能关闭清理窗口。清理结束后主窗口旧改名预览清空，需要重新扫描。建议在未安装的字体素材目录使用；本工具不处理字体安装注册信息。此功能不是按字体内部家族名称去重，也不比较视觉相似字形。

### 同名字体对比

在主界面「重复字体清理」右侧点击「同名字体对比」。扫描范围沿用主窗口所选目录、扩展名与子目录选项。按文件名（不含扩展名、忽略大小写）或字体内部完整名称匹配，关联的候选合并为一组，不以家族名直接合并不同样式。

左侧选择组，右侧并列比较内部完整名称、样式、版本、文件大小、字形数、字符数、完整 SHA-256 与路径。这里是字体信息对比，不是字形图像预览；字形数和字符数更大不代表质量更好。内容是否相同会明确标示。

点击要保留的文件行，再点击「保留选中的这一份」。只有明确指定保留项的组才进入清理范围；未选择的组不处理，也可以取消本组清理。确认后，该组其余文件移入回收站。每个文件按扫描时各自的指纹重新校验，允许用户明确选择同名不同内容的版本；保留项丢失或内容变化则拒绝清理。完成后原有重复扫描与改名预览失效，需要重新扫描。

### 共用首次扫描结果

主界面一次扫描建立改名、重复字体、同名字体共用结果。目录只遍历一次，字体信息只解析一次；只有大小重复或名称匹配的候选计算内容指纹。打开两个清理窗口直接使用内存结果，不再扫描文件。更换输入目录不会自动替换已扫描结果，需主动重新扫描。改名执行或清理执行后共用结果失效，需主界面重新扫描；实际清理前仅重新校验涉及的文件。

字体信息读取使用固定 10 个工作线程；进度按实际完成数量显示，结果按原始文件顺序汇总，保持改名后缀和重复组顺序稳定。内容指纹校验、实际改名与回收站操作仍顺序执行。
