# Python 小工具

每个工具放在按用途命名的独立文件夹中，独立启动、独立配置、独立保存数据，互不干涉。

| 工具 | 用途 | 启动 |
|---|---|---|
| [开业场景强随机生成器](./开业场景强随机生成器/) | 11维独立随机，生成可编辑、可复制的商业开业场景提示词 | 双击工具内的 `启动.bat` |
| [字体批量改名](./字体批量改名/) | 按字体名称预览并批量改名，重名处理与 CSV 日志 | 首次 `install.bat`，随后 `启动.bat` |
| [六爻摇卦](./六爻摇卦/) | 三枚铜钱起卦动画，显示本卦、动爻与之卦 | 双击工具内的 `启动.bat` |
